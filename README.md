# 💻 Desenvolvimento Web

Repositório dedicado ao armazenamento e à apresentação de projetos e atividades acadêmicas desenvolvidos durante minha graduação em **Engenharia de Software no UNIPÊ**.

O foco está no aprendizado e na aplicação prática de conceitos de desenvolvimento Front-end, explorando a estruturação de páginas, estilização de interfaces e implementação de funcionalidades interativas.

## 🎯 Objetivo

Documentar minha evolução no desenvolvimento web por meio de projetos práticos, exercícios e aplicações desenvolvidas ao longo da graduação.

## 🛠️ Tecnologias e Ferramentas

- **HTML5:** estruturação e organização de páginas web.
- **CSS3:** estilização e construção de interfaces.
- **JavaScript:** lógica de programação e interatividade.
- **Bootstrap:** biblioteca para desenvolvimento de interfaces responsivas.

## 🎓 Formação Acadêmica

**Curso:** Engenharia de Software  
**Instituição:** UNIPÊ — Centro Universitário de João Pessoa.

## 🚀 Evolução e Aprendizado

Este repositório está em constante atualização, acompanhando meu desenvolvimento acadêmico e a aquisição de novos conhecimentos em programação e desenvolvimento web.
